# Breakout Session 3: Interactive and Dashboard Visualizations

## Overview

This breakout exercises the concepts from **Notebook 03** (Tableau and Dashboard Visualizations). You will build interactive visualizations using Plotly and explore dashboard layouts.

## Getting Started

All data files and the exercise notebook are included in this directory.

```
breakouts/S3/
└── breakout-S3.ipynb   # Exercise notebook
```

The breakout uses the BII dataset from `../../data/bii_data_w_categories.csv`.

## Instructions

1. Open `breakout-S3.ipynb` in Jupyter
2. Follow the prompts in each cell
3. Experiment with Plotly's interactive features (hover, zoom, selection)

## Prerequisites

```bash
pip install plotly pandas numpy seaborn
```

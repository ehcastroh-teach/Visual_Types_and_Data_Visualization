# Breakout Session 2: Multi-Library Visualization

## Overview

This breakout exercises the concepts from **Notebook 02** (One Chart Across Several Visualization Libraries). You will recreate the same plot using Pandas, Matplotlib, Seaborn, and Plotnine to internalize how each library approaches the Grammar of Graphics.

## Getting Started

All data files and the exercise notebook are included in this directory.

```
breakouts/S2/
└── breakout-S2.ipynb   # Exercise notebook
```

The breakout reuses the Iris dataset from `../../data/Iris.csv`.

## Instructions

1. Open `breakout-S2.ipynb` in Jupyter
2. Follow the prompts in each cell
3. Try to produce the target visualization using each library before checking hints

## Prerequisites

```bash
pip install matplotlib pandas numpy seaborn plotnine
```

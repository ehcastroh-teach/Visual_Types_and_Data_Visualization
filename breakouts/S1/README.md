# Breakout Session 1: Plotting with Matplotlib

## Overview

This breakout exercises the concepts from **Notebook 01** (Visualization Principles with Matplotlib and Seaborn). You will practice creating line, scatter, box, and histogram plots using real-world stock and temperature data.

## Getting Started

All data files and the exercise notebook are included in this directory. No external downloads are needed.

```
breakouts/S1/
├── breakout-S1-matplotlib-v2.ipynb   # Exercise notebook
├── breakout1-data/
│   ├── google_data.txt               # Google stock data
│   ├── yahoo_data.txt                # Yahoo stock data
│   └── ny_temps.txt                  # New York temperature data
└── answer.png                        # Reference answer plot
```

## Instructions

1. Open `breakout-S1-matplotlib-v2.ipynb` in Jupyter
2. Follow the prompts in each cell
3. Compare your result against `answer.png` when finished
